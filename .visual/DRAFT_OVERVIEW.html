Jarvis Visualizer - Draft Overview

Phase 2+ Standalone Speaking Aperture

1. Design Anchor & Inspiration

Anchored directly to the design system established in jarvis-blueprint.html:

  • Stolen with intent: Triple concentric rotating rings, pulsing arc-cyan core, high-contrast monospace status telemetry.
  • Avoided (Anti-Slop): No purple gradients, no cartoonish audio bars, zero unicode emojis, zero default fonts (system-ui / Inter).

2. Typography & Palette Spec

  • Display: Archivo (geometric, technical weight 800)
  • Telemetry / Captions: IBM Plex Mono (400 / 500)
  • Colors: Void (#070b0e), Obsidian (#0d1419), Arc Glow (#59c3e3), Luminescent Core (#bdf0ff)
